# 01. MCP — Model Context Protocol

## Overview | نظرة عامة

يتناول هذا البحث مفهوم **Model Context Protocol (MCP)**، وهو بروتوكول مفتوح يوفّر طريقة موحّدة لتواصل تطبيقات الذكاء الاصطناعي مع الأدوات ومصادر البيانات.

يركّز البحث على فهم آلية عمل MCP، والفرق بينه وبين واجهات برمجة التطبيقات (APIs)، وكيف يمكن أن يساعد في ربط وكلاء الذكاء الاصطناعي بأنظمة مختلفة بطريقة أكثر تنظيمًا ومرونة.

## Research Question | سؤال البحث

كيف يمكن لـ MCP أن يجعل توصيل الوكيل الذكي بالأدوات ومصادر البيانات أكثر تنظيمًا ومرونة؟

## Key Concepts | المفاهيم الأساسية

### 1. What is MCP?

هو بروتوكول مفتوح يحدّد طريقة مشتركة لتواصل تطبيقات الذكاء الاصطناعي مع الأدوات ومصادر البيانات، مما يساعد على تنظيم عمليات التكامل وتسهيل إعادة استخدام الإمكانات المتاحة.

### 2. MCP vs. API

توفّر الـ API واجهة للتعامل مع نظام أو خدمة برمجية، بينما يحدّد MCP طريقة موحّدة لتواصل تطبيقات الذكاء الاصطناعي مع الأدوات والموارد المتاحة.

ولا يُعدّ MCP بديلًا عن الـ APIs؛ إذ يمكن لخادم MCP استخدام API للوصول إلى الأنظمة والبيانات.

### 3. Core Components

- **Host:** تطبيق الذكاء الاصطناعي الذي يتفاعل مع المستخدم.
- **Client:** الجزء المسؤول عن التواصل باستخدام بروتوكول MCP.
- **Server:** يوفّر الأدوات والموارد التي يمكن للتطبيق الوصول إليها وفق الصلاحيات المتاحة.

### 4. MCP Server Capabilities

- **Tools:** وظائف يمكن استخدامها لتنفيذ مهام، مثل البحث عن العقارات.
- **Resources:** بيانات ومحتويات يمكن الاستفادة منها لتوفير السياق، مثل معلومات العقارات.
- **Prompts:** قوالب تعليمات جاهزة تساعد على تنظيم بعض المهام.

## Real-World Example | مثال تطبيقي

لنفترض أننا نطوّر وكيل ذكاء اصطناعي لمكتب عقارات، يحتاج إلى الوصول إلى عدة أنظمة:

- نظام بيانات العقارات للبحث عن الشقق ومعلوماتها.
- نظام إدارة العملاء (CRM) للوصول إلى بيانات العملاء المصرّح بها.
- نظام المواعيد للتحقق من الأوقات المتاحة لمعاينة العقارات.

يمكن استخدام MCP لتنظيم إتاحة الأدوات والبيانات لهذه الأنظمة عبر خوادم MCP مناسبة.

عندما تطلب إحدى العميلات شقة قريبة من الجامعة وضمن ميزانية محددة، يستطيع الوكيل استخدام أداة البحث عن العقارات، ثم الاستفادة من أداة فحص المواعيد عند الحاجة.

يساعد هذا الأسلوب على تنظيم التكاملات وتسهيل إضافة أدوات ومصادر جديدة مستقبلًا، مع ضرورة مراعاة دقة البيانات والصلاحيات والأمان.

**ملاحظة:** هذا المثال توضيحي لفكرة MCP، وليس تنفيذًا فعليًا لتكامل أو خادم MCP.

## Key Benefits | الفوائد الرئيسية

- توحيد طريقة التواصل بين تطبيقات الذكاء الاصطناعي والأدوات.
- تنظيم الوصول إلى مصادر البيانات المختلفة.
- تسهيل اكتشاف الأدوات المتاحة واستخدامها.
- دعم قابلية التوسّع وإضافة مصادر جديدة.
- إمكانية الاستفادة من APIs وأنظمة موجودة مسبقًا.

## Conclusion | الخلاصة

يساعد MCP على تنظيم طريقة تواصل تطبيقات الذكاء الاصطناعي مع الأدوات ومصادر البيانات من خلال بروتوكول مشترك. وفي مثال وكيل العقارات، يمكن أن يسهّل الوصول إلى بيانات العقارات ونظام العملاء والمواعيد، مع تقليل الحاجة إلى بناء أسلوب اتصال مختلف لكل أداة داخل التطبيق.

ومع ذلك، لا يضمن MCP وحده صحة البيانات أو أمان النظام؛ إذ تعتمد هذه الجوانب على جودة الأنظمة المتصلة، وإدارة الصلاحيات، والتحقق من النتائج.
